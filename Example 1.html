Vliegtickets verkopen als Partner

Mogelijkheden

Ben je werkzaam voor een reisorganisatie én geïnteresseerd in het verkopen van onze vliegtickets? We bieden je de volgende mogelijkheden:

  • Via een API-verbinding
  • Via onze Partner Portal
  • Via een GDS (Amadeus, Travelport en Sabre)

Via een API-verbinding

API staat voor Application Programming Interface. Dit is een verbinding die ervoor zorgt dat je website kan communiceren met ons boekingssysteem. Op deze manier kunnen klanten eenvoudig via je website onze vliegtickets en extra producten boeken. Je kunt kiezen voor een directe API-verbinding of via een technische tussenpartij.

Geïnteresseerd? Meer informatie

Via onze Partner Portal

Als reisagent kun je contact met ons opnemen voor een Partner Portal-account. Het Portal is een website speciaal voor reisagenten waarin je direct vliegtickets en extra producten boekt. In het Partner Portal heb je daarnaast de mogelijkheid om gratis 4x24H een optie op een boeking te nemen.

Geïnteresseerd? Meer informatie

Via een GDS (Amadeus, Travelport en Sabre)

Een Global Distribution System (GDS) is een systeem waarmee je real-time bij ons vliegtickets en extra producten kunt boeken. Wij werken hiervoor samen met de bedrijven Travelport (Galileo), Sabre en Amadeus. Je boekt bij ons eenvoudig én zonder papierwerk. Als de boeking geslaagd is, ontvang je per e-mail een boekingsbevestiging.
